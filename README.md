# Task 14 – Basic Sales Summary

## 📌 Project Overview

As part of my Data Analytics Internship, I completed Task 14: **Basic Sales Summary** using Microsoft Excel.

The objective of this task was to analyze the Superstore sales dataset and create a simple business summary using three key performance indicators (KPIs).

## 🎯 Objective

- Calculate Total Sales
- Calculate Average Sales
- Calculate Transaction Count
- Create a summary sheet containing 3 KPIs
- Practice using Excel formulas for basic sales analysis

## 🛠️ Tools Used

- Microsoft Excel
- Superstore Dataset

## 📊 Dataset

The Superstore dataset contains sales transaction records with information such as orders, customers, products, regions, sales, and profit.

For this task, the **Sales** column was used to calculate the required KPIs.

## 📈 KPIs Calculated

| KPI | Result |
|---|---:|
| Total Sales | $2,297,200.86 |
| Average Sales | $229.86 |
| Transaction Count | 9,994 |

## 🧮 Excel Formulas Used

### Total Sales
=SUM('SampleSuperstore'!J2:J9995)

Average Sales
=AVERAGE('SampleSuperstore'!J2:J9995)

Transaction Count
=COUNT('SampleSuperstore'!J2:J9995)
